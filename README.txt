FRAMORYX — YOUR GAMING TOOLKIT
Version 0.3.0 | C++ and Qt | Windows x64 / Linux x86-64

Extract the complete package. Open Framoryx.exe on Windows, or run the
AppImage / AppRun on Linux. Select a running game and Start capture,
then Show overlay. Overlay Studio controls readouts, layouts and sizing.

The default capture path loads no code into your game. Optional hooks
and game layers require explicit selection and may conflict with games
or anti-cheat rules. Use at your own risk; no ban-free guarantee is made.

Windows builds are unsigned. Verify the published SHA-256 checksum.
Keep the application folder and runtime files together.

Windows extra gain and microphone processing require Equalizer APO
configured for the intended devices. Linux audio uses PipeWire. RNNoise
is prepared from the official release after you request it. Audio Apply
is explicit; microphone tests record only after you choose Record test.

Source builds of the shared desktop use CMake and Qt. The separate native
Windows build is the monitoring engine and diagnostic harness.
See README.md and docs/BUILDING.md for source, validation and dependency notices.
