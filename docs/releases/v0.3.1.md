# Framoryx 0.3.1

## Overlay

- New setups start capture automatically. On Windows, enable **Show overlay automatically** in Settings to show the external HUD for eligible foreground games. Use process rules to explicitly allow or block individual games.
- The Windows external HUD follows the game's client area as the game moves or resizes. It fits within the visible game area and scales down for small windows.
- Overlay Studio has six edge and center presets in a compact grid. Choose **Custom** to edit X and Y directly or drag the preview. Saved legacy presets move to the corresponding edges.
- Choose an installed font, rename any of the sixteen readouts, or select the animated Rainbow accent. Optional neon text glow works with every accent. Optional temperature colors tint CPU and GPU values by range. The font, glow and temperature color settings carry across games.
- **Color readouts by value** in Overlay Studio adds live mint, amber and coral bands. FPS uses 30 and 60 FPS as breakpoints, and frame time uses about 16.7 and 33.3 ms. CPU, GPU, RAM and VRAM usage use 65% and 90%. Temperatures use 65°C and 80°C. An active numeric FPS limit uses the FPS bands. Power and clock readings keep their normal style because their ranges vary by GPU. The separate temperature-only switch remains available.
- Rainbow now moves across the text in a 3.2-second cycle. **Neon text glow** follows the moving colors. When value colors are active, tinted values use their own color and the other text keeps the selected accent.
- Windows and Linux X11 can show an optional hardware-only HUD on the desktop. The desktop HUD uses the base overlay preferences.

## Preferences and monitoring

- Clicking the tray icon restores the main window, including when Framoryx starts hidden. Overlay edits save during longer adjustments and flush when the window hides or the app quits.
- Windows displays a themed warning when choosing Auto or manual hook mode, or when attaching to a game. Auto starts with the external overlay and can switch after you approve a hook for a specific game. You can hide the repeated explanation and still confirm the specific target before attaching.
- Improved hardware sensor selection and telemetry labels on Windows and Linux. Missing measurements remain unavailable.
- Hardened the Windows hook's process and frame data checks and the Linux game layer's configuration parser.

## Linux launch options

- For Steam launch options that work across launches, extract the portable Linux archive to a stable folder and copy the launch options from that copy of Framoryx. An AppImage mount path lasts for its current session.
- A new in-game font takes effect on the next monitored game launch. Copy the Steam launch options again after changing the font.
