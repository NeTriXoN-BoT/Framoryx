# Framoryx 0.2.1 — Fit your setup

**Unsigned Windows build.** No Authenticode publisher certificate is included. Windows may show an unknown-publisher or SmartScreen prompt. Compare the ZIP with its published SHA-256; this verifies download integrity, not safety or anti-cheat approval.

## Improved

- Maximizing and restoring preserve the selected desktop percentage and the UI's proportions. The canvas stays centered on wide displays. Auto considers resolution, Windows DPI and available work area; smaller windows fit the canvas without stretching it.
- Game Rules adapts its size when moved between monitors with different DPI.
- **Bassy voice** warms thin microphone recordings with a compensated low shelf and reduced midrange boxiness. Saved and custom EQ settings restore the correct preset label.
- Audio gain, bass and microphone configuration writes are serialized and atomic. File work runs on background workers, while sliders and controls remain available.
- Cached RNNoise DLLs are checked for changes. Apply stages verified bytes separately beside the APO configuration, so moving a download does not break an installed microphone chain.
- Local config paths, bounded file reads, metadata depth, temporary-file creation, collector cleanup and worker failure handling have been hardened.
- Static pages reuse rendering caches; animation blits are limited to the changed area. Removed an unused legacy overlay control and unnecessary graph allocations.
- Download cards point to the public latest release. An anonymous CI job downloads the ZIP and verifies its checksum; no GitHub login is required.

## Validation

The build includes 110 core, 20 gain, 38 microphone/bass and 49 file-integrity/concurrent-audio checks, plus 20,000 deterministic malformed-input cases. Address/undefined-behavior sanitizer runs cover those core/audio suites. Native UI checks exercise scaling, maximize/restore, profiles, audio controls and process rules. See the [validation record](../VALIDATION.md) and [audit findings](../AUDIT.md) for results and remaining limits.

## Compatibility

The default monitor uses ETW and a desktop overlay. Optional in-game hooks remain experimental, require explicit opt-in and can conflict with games or security tools. The earlier Defender-blocked injection soak remains incomplete; no protections were bypassed. There is no universal game or ban-free guarantee.

Additional audio effects require Equalizer APO configured for the selected device. A configured status does not establish audible processing. A Linux desktop application is not included.
