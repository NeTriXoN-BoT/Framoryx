# Framoryx 0.3.0 — Your game, your way

**Development version.** The public stable release remains 0.2.3 while platform integration and packaging checks continue.

## Interface and everyday use

- Shared native C++ and Qt Quick interface for Windows and Linux, with the same artwork, motion effects and responsive layout.
- Automatic DPI rendering, display-aware interface sizing and manual percentage controls; layouts adapt to maximized and smaller windows.
- Technical headline typography with a blinking terminal cursor that pauses with ambient motion.
- Cached pages keep their controls alive between visits. Backend updates are coalesced separately from live slider feedback; slider handle geometry stays fixed during fast dragging.
- Optional sign-in startup, quiet startup, minimize to tray, close to tray and automatic capture. A missing system tray keeps the app accessible in the taskbar.
- Offline, searchable release history includes every published Framoryx version.

## Overlay and games

- Ten readouts, draggable positioning, readout reordering, font sizing, percentage scaling, named presets and preset import/export.
- Glass, Compact, Telemetry Bar, Minimal and Dashboard layouts; ten accent colors.
- Background opacity now reaches 0%, preserving visible readouts against a completely transparent background.
- A searchable process list adds executable names directly to allow/block rules. System and known anti-cheat processes remain protected.
- Game-supported cap overrides use the selected game's launch options where a supported method exists. Unsupported hard caps are identified honestly; high frame rates may affect physics, timing or stability.
- Clearer anti-cheat responsibility notices. Allow lists and clear scans do not establish game approval.

## Audio and Linux

- Output volume up to 200%, compensated bass, three-band microphone EQ and Bassy Voice.
- Opt-in five-second microphone recording and playback, with a live level meter and in-memory samples.
- Native Linux integration for MangoHud monitoring/limits, optional Gamescope launch sizing and PipeWire processing. Required components and compositor restrictions appear in Setup.
- Automatic verified RNNoise preparation with manual update controls. Audio changes require explicit Apply.

Windows builds are unsigned. Integration tests and game/hardware coverage are documented separately; no universal game, ban-free or zero-overhead guarantee is made.
