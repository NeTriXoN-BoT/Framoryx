# Framoryx 0.3.0 — Your game, your way

## Interface and everyday use

- Shared native C++ and Qt Quick interface for Windows and Linux, with the same artwork, motion effects and responsive layout.
- Automatic DPI rendering, display-aware interface sizing and manual percentage controls; layouts adapt to maximized and smaller windows.
- Technical headline typography with a blinking terminal cursor that pauses with ambient motion.
- Cached pages keep their controls alive between visits. Backend updates are coalesced separately from live slider feedback; slider handle geometry stays fixed during fast dragging.
- Optional sign-in startup, quiet startup, minimize to tray, close to tray and automatic capture. A missing system tray keeps the app accessible in the taskbar.
- Offline, searchable release history includes every published Framoryx version.

## Overlay and games

- Sixteen readouts, draggable positioning, readout reordering, font sizing, percentage scaling, named presets and preset import/export.
- Glass, Compact, Telemetry Bar, Minimal and Dashboard layouts; ten accent colors.
- Background opacity now reaches 0%, preserving visible readouts against a completely transparent background.
- A searchable process list adds executable names directly to allow/block rules. System and known anti-cheat processes remain protected.
- Game-supported cap overrides use the selected game's launch options where a supported method exists. Unsupported hard caps are identified honestly; high frame rates may affect physics, timing or stability.
- Read-only CPU/GPU/VRAM usage, temperatures and available clocks, power and fan readings. Unsupported sensors stay unavailable; hardware polling runs on a worker.
- Clearer anti-cheat responsibility notices. Allow lists and clear scans do not establish game approval.
- OpenGL and Vulkan on Linux use the same custom HUD and support live frame-limit changes. A separate explicit layer identity avoids activating a second system MangoHud layer.
- Block rules take effect in a running game and remain enforced when capture is restarted. External monitoring is used when a selected layer is unavailable and the game exposes usable events.

## Audio and Linux

- Native X11 and Wayland UI, with separate compositor tests for OpenGL/Vulkan overlays and the deployed Linux package.
- Fixed automatic X11 capture when no previous capture connection exists.
- Output volume up to 200%, compensated bass, three-band microphone EQ and Bassy Voice.
- Opt-in five-second microphone recording and playback, with a live level meter and in-memory samples.
- Native Linux integration for MangoHud monitoring/limits, optional Gamescope launch sizing and PipeWire processing. Required components and compositor restrictions appear in Setup.
- Automatic verified RNNoise preparation with manual update controls. Audio changes require explicit Apply.

## Reliability and packaging

- Restored game selections are applied before automatic capture; expired window selections return to Auto.
- Damaged preferences are backed up before defaults are saved. Unsupported settings versions and unsafe configuration paths are preserved.
- Fast volume gestures keep their final value, and external volume changes update the slider without rebuilding pages.
- Sign-in launch follows the separate quiet-start preference. Capture and game launch are separate actions.
- Game-layer launches wait for a pending compatibility check and use external monitoring if the check takes too long.
- Linux audio routes remain tied to the selected physical device. Filter processes stop on exit, and connected game layers release their HUD and limit when the controller disconnects.
- Linux game-layer loading supports portable folders containing spaces.
- Wayland surface cleanup tolerates desktops without keyboard/seat objects. Framoryx mode no longer creates an unused game-keyboard listener, and normal game exit is covered by the live checks.
- Removed unused upload, shell and hidden shortcut features from the bundled runtime; hardened parsing, formatting and font allocation checks.
- Windows CPU clock reporting uses the operating system's power information without installing a sensor driver.
- Windows ZIP, Linux AppImage and portable Linux archive include the shared desktop and required runtime files. Public downloads have SHA-256 checksums.
- Linux packages explicitly deploy Wayland's EGL client integration alongside the platform plugins and test the AppImage on native Wayland without Qt build paths.

Windows builds are unsigned. Integration tests and game/hardware coverage are documented separately; no universal game, ban-free or zero-overhead guarantee is made.
