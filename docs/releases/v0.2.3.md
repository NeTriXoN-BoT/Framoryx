# Framoryx 0.2.3 — Feature reliability

- Finish accepted gain, bass and microphone changes during shutdown; coalesce rapid edits independently for mic and bass.
- Consume RNNoise completion state consistently and cancel deferred microphone Apply when its settings change; browsing dropdown choices preserves it.
- Commit a slider's final value when mouse capture is interrupted and synchronize the percentage after disabling gain.
- Keep capture failures visible, roll back a failed overlay toggle and retain the previous hook state on attach failure.
- Export quoted UTF-8 CSV with relative timestamps and locale-independent numbers; clear stale FPS limits when reloading settings.
- Crop transition snapshots to the content canvas to reduce temporary bitmap storage, especially on wide displays.
- Group the compatibility selector consistently; show contextual audio help and explain fitted manual UI sizing.
- Add isolated full control-flow, native screenshot, missing-runtime and single-instance checks, plus official RNNoise download/probe/staging integration.

The program is **unsigned**. Audio processing above the Windows volume limit and microphone processing require Equalizer APO enabled for the selected devices. Hardware listening quality, every commercial game and every driver/display combination are outside automated fixture coverage. Optional hooks carry compatibility and anti-cheat risks. See [validation](../VALIDATION.md) for the completed checks and their scope.
