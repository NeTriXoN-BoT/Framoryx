# Framoryx 0.2.0 — Overlay Studio

**Unsigned Windows build:** Framoryx has no Authenticode signing certificate. Windows may show an unknown publisher or SmartScreen warning. Compare the ZIP with its published SHA-256; a matching hash checks file integrity, not security or publisher certification.

## New

- Separate Output and Microphone audio views, headroom-compensated bass and three-band voice EQ.
- Optional RNNoise VST2 configuration with Natural, Balanced and Strong presets. Requires separately installed Equalizer APO and the official external plugin; no audio is recorded by Framoryx.
- Rounded FPS stepper and redesigned process-rule cards with inline validation.

- Glass, Compact and Telemetry Bar HUD layouts.
- Ten selectable readouts with per-game profiles, four accent colors, opacity and corner controls.
- Automatic HUD sizing plus 50–300% overrides, with font atlases rebuilt at the effective size.
- DPI/work-area-aware desktop sizing with percentage overrides.
- A high-resolution, refresh-aware UI animation clock, continuous header motion and cached panel rendering.
- Eased page transitions, switch movement, hover highlights, animated metrics and a live graph pulse.
- DX12 in-game HUD support with observed-queue selection and conservative multi-queue fallback.
- Compatibility inspection, tray access, desktop shortcuts and existing-instance activation.

## Existing toolkit

PresentMon ETW capture, rolling frame graph, 1% lows, CSV export, optional DXGI pacing, x86 DX11 support, borderless restoration, process rules, Windows volume and optional Equalizer APO gain.

## Read before enabling hooks

The default monitor does not inject. Optional hooks remain experimental and can conflict with games or security tools. Defender quarantined the optional injection soak helper during development; its interrupted run is not a pass. No protections were bypassed. Read [compatibility and security notes](../COMPATIBILITY.md).

Audio configuration has been tested in isolated files. Device-level audible processing still requires verification after APO setup. Commercial-game compatibility has not been certified. A Linux desktop build is not included.

See the [validation record](../VALIDATION.md) for completed checks and the interrupted injection soak.
