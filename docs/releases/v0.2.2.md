# Framoryx 0.2.2 — Dependency hardening

**Unsigned Windows build.** Framoryx has no Authenticode publisher certificate. Windows may display an unknown-publisher or SmartScreen prompt. The release includes SHA-256 checksums for download integrity.

## Fixed

- Reworked the remaining dependency/compiler findings: explicit memory-buffer partitions, checked font allocations, arithmetic widened before multiplication, and initialized CET fallback operands.
- Numeric scalar formats now come from typed literal pools. Unsupported or unsafe conversions fall back to safe numeric defaults. Localization and prefix text are rendered as data.
- The portable compiler's two header patches verify complete before/after hashes, safely accept an already-patched header and refuse unknown inputs.
- Added a headless dependency regression suite for numeric edge cases, format rejection, font atlases, triangulation and CPU draw data. It runs in x64/x86 builds and Linux core CI, with sanitizer support.
- Graphics, capture and all seven window-layout regressions now run on GitHub's isolated Windows runner, keeping test windows off the development desktop.

The fresh full native CodeQL security-extended scan cleared the 20 previously open alerts without query exclusions or alert dismissals. See the [audit record](../AUDIT.md) and [dependency patch details](../DEPENDENCY-PATCHES.md) for scope and verification.

## Compatibility

Monitoring, overlay customization, frame limiting, borderless play, audio settings and scaling retain their existing controls. Optional game hooks remain experimental and do not carry a ban-free or universal compatibility guarantee. The build is unsigned; a clean automated scan is not a security certification. Additional audio processing still requires Equalizer APO configured for the chosen device.
